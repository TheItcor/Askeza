Askeza(0) - язык программирования с виртуальными регистрами и стеком как цетральной системой структуры данных.

(0) - бывшее название VSMI.  
(1) - На данном этапе язык интерпретируемый, позже планируется переход на компиляцию через компилятор С (возможно TCC, clang).

Логика версий: число.число.число "название"  пример: 1.0.0 "Socrates"  
├─ X: MAJOR (большие изменения) - может сломать совместимость  
├─ Y: MINOR (новые возможности) - обратно совместимые  
└─ Z: PATCH (новые исправления) - обратно совместимые  



**Особенности:**
- Стек на 1024 элементов (по умолчанию)  
- Виртуальные 4 регистра (по умолчанию)  
- Интерпретируемый(1)  
- Конкатенативный  


Догматы (принципы) языка:
1. Работа в стеке ведётся исключительно с верхними элементами стека.  
2. Возвращаемое значение всегда будет уходить на специальный регистр.  
3. Код не должен быть избыточным.  
4. Код должен оставаться читабельным.  
5. Одна инструкция - одно действие.  


# Интерпретатор

Интерпретатор скомпилированный из .c файла работает по следующей схеме:
Чтение файла -> лексический анализ -> импорт файлов (если есть) -> парсинг инструкций -> непосредственное выполнение

Запуск файла:
```
ask main.i
```

Запуск файла с отладкой:
```
ask -dbg main.i
```

Изменить размер стека в элементах (по умолчанию 1024 элементов):
```
ask s2048
```

Изменить количество регистров (по умолчанию 4 регистра):
```
ask r8
```

все параметры:
```
ask (вкл дебаггер) (размер стека) (кол-во регистров) (файл)
```

## Деббагер 

Выводит информацию о стеке и регистрах после каждой итерации с ними.
Пример:
```
push s 10
push s 30
add s
push r0 s
print r0
end 0
```

`ask -dbg main.i`

```
s:[10]
s:[10, 30]
s:[40]
r0:[40]
40
```

### Будущий компилятор

Схема работы будущего компилятора:

файл.i 
-> препроцессор работает с import 
-> чтение файла.i построчно 
-> разбиение на токены
-> чтение токенов
-> запись в промежуточный файл.c
-> компиляция файл.c через C-компилятор 
-> удаление промежуточного файла.c 
-> файл.o

## Ошибки интерпретатора

Во время лексического анализа происходит анализ на синтаксические ошибки. Так же во время работы интерпретатор может выдать одну из нескольких ошибок. 

| Ошибка                                             | значение                             |
| -------------------------------------------------- | ------------------------------------ |
| Fatal Error: stack overflow                        | Стек переполнен                      |
| Syntax Error: unknown instruction at line /number/ | Синтаксическая ошибка + номер строки |


# Стек и регистры

Стек - центральная структура данных, рабочая память для виртуальной машины. Все вычисления происходят через операции на вершине этой структуры (LIFO). Размер по умолчанию 1024 элементов по 4 байтов каждый. 


В Askeza всего 4 (5) регистра:
- r0, r1, r2, r3. Все они могут хранить только одно значение до 4 байтов. Это не настоящие регистры процессора как в assembly, а лишь их виртуальная реализация. 
- rr (return register) - регистр куда предлагается возвращать результат выполнения функций-меток.

Элемент стека или регистр могут хранить следующие типы данных:
- int (4 байт)
- char (1 байт)
- float (4 байт)

### Синтаксический сахар

#### push
Можно отправлять в стек сразу несколько элементов или даже целые "строки":

```
push s 10 20 30 40 
```
В этом случае 10 - будет на дне стека, а 40 наверху стека.

```
push s 'cat'
```
В стек будет отправлено 't' 'a' 'c', где 'c' - будет наверху стека. Т.е. слово будет записано в стеке задом-наперёд.

#### print
помимо вывода одного элемента:
```
push r0 'a'
push s 'b'

print r0 // --> a
print s  // --> b
```

можно выводить кусками из стека:
```
push s 20 10 40

print s 3
```
Отправляем на стек 3 числа и выводим последние 3 элемента на стеке. Вывод начнётся с самого верхнего числа "40".

Вывод "строки":
```
push s 'Hello'

print s 5
```
Отправляем на стек 5 символов и выводим последние 5 элемента на стеке. В стек запишится: 'o','l','l','e','H', а выведется: 'H','e','l','l','o'.





## Функции
Нет привычного понимания функции как в высокоуровневых языках. Вместо этого есть метки, возвраты и вызов
Для объявление "функции" нужно написать `название_метки:` заранее до main. По-существу метка раби возвратом. Пример:

```
print_hello:
    /* using stack */    // Предупреждаем, что функция будет работать только со стеком
    push s 'hello world' // будет отправлено на стек как 'h', 'e', 'l'...
    print s 11 // вывести в консоль последние 11 элементов
    ret       // пустой return - ничего не возвращать.
    
    
main:
    jmp print_hello
```


```
print two:
    /* using r0 */  // Предупреждаем о работе r0 в функции
	add r0 2
	push rr, r0 // перемещаем значение из r0 в rr 
	ret rr      // возвращает rr


main:
    jmp two(r0)
```

## Циклы
С помощью меток вы можете создать циклы:.

Реализация цикла for
```
main:
    push r0 0
    
for:

    // тело цикла
    add r0 1
    if (r0 != 10); jmp for; jmp end_for

end_for:
    // продолжение
```

Реализация цикла while
```
main:
    push r0 0

loop:

    // тело цикла
    if (r0 = 1); jmp loop; jmp end loop

end_loop:
    
    // продолжение
```

# Импорт других файлов
В Askeza можно импортировать код из других файлов, а конкретно только метки которые не являются main.

файл lib.i
```
fn square r0:
    mult r0 r0
    ret rr

main:
	push r0 2
	call squre
	print r0
	end 0
```

файл main.i
```
import "lib.i"

main:
	push r0 10
    call squre
    print rr
    end 0
```
Вывод:
`100`

Будьте готовы к тому, что во время выполнения функций ваши регистры/стек могут поменять значения. В особенности регистр rr (return register).



# Рекомендации к оформлению код

## Оформление функций

- Название функций должно быть в snake_style.
- Если функция что-то возвращает, то должна это возвращать в специальный для этого регистр rr

## Отступы

- Рекомендовано делать 4 пробела после метки в том числе main:
```
main:
    push s 'hello, world!'
    print s 13

```

* между функцией и остальным кодом (в том числе другими функциями) должно быть 2 отступа:
```
fn print_cool s:
    // use stack
    push s 'cool'
    print s 4


main:
	call print_cool
```

* между метками (в том числе main) должен быть 1 отступ
```
main:
	if (r0 != 0); jmp then;

then:
    call print_cool
```
